ECoG Joystick Decoding — continuous 2D cursor position decoding from intracranial ECoG using ridge regression over frequency-band envelope features and LMP. Within-subject 5-fold contiguous CV across 4 subjects, achieving up to r = 0.69 with per-channel CV selection and hybrid LPF/Kalman postprocessing.
